## Linked article

Fetched from https://chenglou.me/handwired/ and https://github.com/chenglou/handwired (README) on 2026-10-24.

**Claim:** "Turn your regular JavaScript code into a neural net. No training, exact yet also fully differentiable, runnable in a browser without GPU."

**How it works:** a program is if-else, loops and state; Handwired rewrites those into matrix multiplication plus ReLU over floats. The README's example:

```ts
const a = 5
const result = (a > 4) ? 10 : 12

// becomes
const above4 = Math.max(0, a - 4) - Math.max(0, a - 5) // 1 if a > 4, else 0
// both branches compute, and above4 picks one
const result = above4 * 10 + (1 - above4) * 12
```

Comparisons become differences of two ReLUs; branches are evaluated and selected by a mask. The `+`, `*` and `relu` are then collected into one giant matmul, executed in JS or on WebGPU.

Consequences the README lists: because only those two primitives are used, (1) the full program stays differentiable, (2) weights need no training since they are written by hand, and (3) GPU techniques — fusion, sparsity, reordering — optimize such minimal primitives well. The landing page backs the claims with three demos: a small OS, a photo gallery and a JSON search.

**Demos (with stated counts):**

- **HandwiredOS / Mini OS** — a small desktop written in JS and transformed by Handwired: giant lists, animation, stacking, scrolling, drag, input, pictures, all rendering to regular DOM. Stated: **9,909 weights, 130 layers, 0 training**.
- **Learned gallery** — "unfreeze a compiled program's weights & train them in real time".
- **Search 100,000 JSON documents** — regex matching, JSON parsing and highlighting written in JS, turned into WebGPU kernels; the landing page claims it "runs in milliseconds over 100k documents".

**Use cases the README floats:** unfreeze the weights and train them ("what does that even do? Let's find out!"); attach a specific frozen program to a generic neural net and train end-to-end ("now a nanoGPT can do both Shakespeare and your particular UI?"); get GPU-level parallelism out of code written in the traditional single-threaded way.

**Repo state:** 825 commits, 1 branch, 2 tags, last commit 2026-10-17 ("lab: an experiment that trains a strict parser's unused table entries…"), co-authored by Claude Code. Local run: `git clone && bun install`, then `bun start`; docs/ , src/ and template/ are the entry points, `lab/` is a set of older experiments. The author's own framing on the landing page and README is experimental ("for fun"), so the exactness claim should be read as a property of the integer-comparison construction shown, not a blanket theorem.
