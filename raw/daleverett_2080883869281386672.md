# Thinking database / infinite context window (Polygres)

Author: dale @daleverett
Posted: 2026-07-25T05:12:30 GMT
URL: https://x.com/daleverett/status/2080883869281386672

At Polygres, we're working on a different kind of database: a thinking database. For most of software history, the division of labour was simple.

The database stored the facts.
The application retrieved them.
The human did the thinking.

AI agents change that arrangement. An agent is expected to investigate, remember, connect evidence and make decisions. But it can only reason over the information available inside its current context window.

We have built systems with enormous institutional memory, then given our agents the equivalent of short-term amnesia.

Not a database that replaces the main model, but one that helps it reason.

It can start with a customer, follow the connected orders and tickets, find similar incidents, filter out irrelevant records and assemble the evidence the model actually needs.

This is what we mean by an infinite context window. It is not one enormous prompt containing your entire company. It is the ability to reach any relevant row, relationship or embedding at the moment it matters. The model's immediate context stays focused, while the knowledge it can draw from becomes as large as the database itself.

The next generation of databases will do more than store the state of an application. They will help agents investigate, connect evidence and understand the world behind the data. Polygres is building towards that future: turning Postgres from a system of record into a system that helps you think.

More context is not the goal. Better context is.

The phrase "infinite context window" can sound like a promise of unlimited consumption: put everything into the model and let it work things out.

The more useful interpretation is the opposite. A thinking database can "reason" over all the data inside it. Which makes it unnecessary to stuff everything into the prompt.

Every row can remain available without being loaded. Every relationship can be followed without being expanded in advance. Every embedding can be searched without exporting it to a disconnected system.

The agent's immediate context stays selective. Its addressable context becomes effectively unbounded.

From systems of record to systems of thought.
