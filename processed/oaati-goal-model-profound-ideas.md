# OAATI: Manage Goals as Outcome → Activities → Actions → Time → Iterate

Craig Perry (@profound_ideas_). X Article. Productivity-system pitch with a course CTA at the end — extract the model, not the prompt funnel.

## Claim

Fragmented tactics (deep work, time blocking, analog vs digital, Notion, morning routines) are nodes in a web, pointless in isolation. Vagueness is where fear and laziness live. Five words: **Outcome → Activities → Actions → Time → Iterate** (OAATI, “oat-ee”).

## Mechanics

1. **One measurable outcome** (Kubrick: filmable). Summit *and* baseline (what you’re climbing away from). Golf example: 9.9 handicap, not “get better.” Sisyphus: pick one mountain.
2. **Work backwards** into activities (driving / approach / putting), then deathly-specific actions, then time so you can calendar-block. Write a full SOP even if wrong — you cannot iterate what does not exist. Skill shrinks the list over time.
3. **Rigid vs loose steps.** Rigid = mechanical checklists (the foundation). Loose = creative/adaptive (idea gen, live rolling). Both specific. Rigid is what lets creativity dance.
4. **What / why / how** on every activity and action; cut what cannot answer. Then **Theory of Constraints** (Goldratt / slowest scout): one bottleneck; pointless work is a symptom you have not found it. “Less is more when less is aimed at your constraint.”
5. **More → Better → New** (Hormozi): reps first, then refine/systematize, then experiment. One living SOP (outcome, activities, actions, times, checklists). Capture feedback; weekly AI pass to update. 10,000 high-quality iterations > 10,000 vague hours.

## Skeptical read

Long, hortatory, course/prompt closer. Goldratt + Hormozi are restated, not extended. Keep OAATI + rigid/loose + constraint as the searchable core.
