# Applied AI Doesn't Work

Vas (@vasuman), Varick Agents. Claims 300+ C-level conversations. Hammer 1990 HBR: IT mechanized old processes. UK DBT Copilot trial: 1.14 actions/user/day; PowerPoint faster but worse; "no robust evidence time savings → productivity"; 72% satisfied. Mollick: individual AI lift ≠ org lift.

Insurance example: 22 elapsed days, 17 minutes of work. Speeding the 17 minutes is a fake 50%. Modern analog: 25 min work, 2 days–2 weeks elapsed.

Don't wait for one ERP. Agents tolerate messy systems; orchestration across existing SoRs. Don't build the same agent 9 ways for 9 acquired process variants — standardize the process first.

Map at department grain: happy path, exception share/cycle/cost, up/downstream, SoR winner, regional variants, touch vs elapsed, AI-ability. Process mining **and** operator interviews (not "AI interviews").

Sort every step: **deterministic** (code), **agentic** (judgment with history, low risk, short outputs), **HITL** (high cost of error; agent assembles evidence). 25-step process → few agents + code + 2 human gates.

Vendor process-reengineering pitch. Extract Hammer + touch-vs-elapsed + three buckets. Raw may be truncated.
