# The AI Engineering Skills Map (Andrew Ng)

@AndrewYNg / DeepLearning.AI: map of what developers should learn and employers should hire for, post-2022 AI build shift. Synthesized from **10k+ job postings**, structured interviews (experts, hiring managers, recruiters), surveys, other online data — “clustering” jobs + expert input for near-future skills.

## Framing

**AI engineering skills** ≠ only the “AI Engineer” title. Like cloud: everyone needs the skills; few hold the specialist title. Applies to full-stack, data, DevOps, ML, AI engineers.

## Four pillars

### 1. Building and deploying AI applications

Core difference vs classic software: **unpredictable outputs** (LLM completions, trained model predictions).

Need:

- Building blocks: LLMs, context engineering, RAG, agentic workflows, ML/DL  
- **Statistical measure / steer / govern** so systems behave more predictably  
- Disciplined **evals + error analysis loops**

### 2. Software engineering fundamentals

Tradeoffs: cost, scalability, reliability, speed, security, privacy. Stack, architecture, data store, testing.

Without fundamentals, vibe-coding with agents means you don’t know which tradeoffs the agent is making or what context to give it. Fundamentals = **precise language to steer agents**.

### 3. Using coding agents

Mental model of how agents work, limits, intervention level, token/time waste.

Practices named:

- Context management  
- Planning vs execution tradeoffs  
- Verifiers / evals so agents close loops  
- Specs (and when not to bother)  
- Multi-agent orchestration  
- Avoid prod-data disasters  
- **Routines to keep trying new tools** as best practices churn  

### 4. Shaping the build

Agents get better at delivering to a clear spec → engineer work shifts **up** to what goes in the spec. Product sense, business context, customer goals, greater ownership/agency. Drive projects: when MVP-to-users vs slow careful build.

## Underlying

**Continuous learning** mindset — practices change fast.

DL.AI focus; Ng promises deeper posts per pillar + fuller map.

## Why it matters

Canonical four-bucket curriculum for agent-era engineering. Unifies eval culture, harness/agent ops, anti-vibe fundamentals, and product ownership (FDE / velocity-pod / agentic-engineer notes) under one hiring/learning frame.

## Skeptical read

High-level map; “10k jobs” methodology not public. DeepLearning.AI product alignment. Still the right checklist for prioritization.
