# 70 Ideas to Reimagine Your Product Process With AI

George (@nurijanian / prodmgmt.world). Listicle of guest workflows (Claire Vo *How I AI*). Not a quote-tweet of something else — a 70-item catalog.

## Pattern (author's closer)

Keep context easy to load. Define success before you design. Make listening and shipping the same loop. Store design choices as files and tests. Monitor agent systems like products.

## Clusters (not all 70)

- **Context:** modular markdown, `decisions.md`, `agents/` in the product repo, session-end writeback, local vs shared rules, customer-quirks ledger via Confluence MCP.
- **Specs:** PRDs as markdown next to code; MCP publish to Notion/Confluence; Gherkin from PRD; evals beside PRD as executable success; golden conversations before UI.
- **Judgment:** few-shot from edited outputs; taste PDF grader; 1–5 scored criteria; exec-role simulation; peer agents (boss/eng/customer); builder+critic.
- **Design:** schema-first then UI; Figma MCP; feature-flag fake frontend; design-system components so agents stop CSS-thrashing.
- **Ops:** Linear columns as cloud-agent state machine; Slack-reaction sandboxes; `/ship` skill; telemetry on skill failures; block raw commits without PR summary.

Catalog, not a method paper. Sources are podcast guests.
